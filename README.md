# Venus Creation Aura

Create a highly elegant, luxurious, and modern website for an art studio named "VENUS - The Creation Aura".

### CRITICAL TECHNICAL REQUIREMENT:
- Build the project strictly using standard Vite + React with Tailwind CSS and standard React Router (react-router-dom) for client-side routing.
- DO NOT use TanStack Router, TanStack Start, or complex TanStack framework features. The build must remain standard Vite to ensure effortless deployment on Vercel and easy code maintainability.

### Design & Visual Identity:
- Color Palette: Warm Cream/Off-white background (#FDFBF7), Deep Navy Blue (#0F1E36) for typography and main elements, Metallic Warm Gold (#D4AF37 / #C5A059) for borders, accents, and subtle glow effects.
- Typography: Elegant Serif fonts for main headers (e.g., Cormorant Garamond / Playfair Display), clean Sans-serif for body text (e.g., Montserrat / Plus Jakarta Sans).
- Aesthetic: Fine art gallery feel, minimal layout, smooth fade transitions, delicate gold lines, luxurious cards.

### Interactive Entry Page (Interactive Landing / Splash Screen):
- When the site loads, display a full-screen landing view (Splash Screen) before accessing the main site content.
- Content on Splash View:
  * Centered VENUS logo with its aura icon / fairy motifs.
  * Headline: "Là où vos plus précieux souvenirs deviennent éternels."
  * Subtext / Call-to-Action: "Cliquez n'importe où pour entrer dans l'atelier" (or an elegant "Entrer dans l'Atelier" button).
- Behavior: Clicking anywhere on this splash screen smooth-fades into the main website view (or smooth scrolls down). Include an option to persist or return to home.

### Main Site Content (Revealed after Splash screen entry):
1. Navigation Bar:
   - Header with logo text "VENUS - The Creation Aura".
   - Links: Accueil, Collections, Services, À Propos, Contact.
   - CTA Button: "Commander une œuvre".

2. Hero Section:
   - Headline: "L'art d'immortaliser l'inestimable."
   - Subheadline: "Des créations artistiques sur-mesure pour figer vos moments les plus précieux."
   - Primary CTA: "Explorer nos collections" | Secondary CTA: "Nos Services".

3. Core Offerings (Collections & Custom Work):
   - Fine Art Portraits: 3 pricing cards (Gamme Prestige 1m x 1m, Gamme Standard 50cm x 70cm, Gamme Essentielle 40cm x 50cm).
   - Resin Art & Precious Memories: Custom resin inclusions (birth keepsakes, wedding memories, custom precious objects).

4. Parallel Services:
   - Event Face Painting: Professional artistic face painting for corporate, private, and birthday events.
   - Art Academy & Workshops: Educational art instruction programs for schools and vacation/holiday art camps.

5. Booking / Contact Form:
   - Interactive form allowing visitors to request a quote or book a service (dropdown options: Portrait sur toile, Résine Art, Face Painting, Ateliers d'Art).
   - Social links (@VenusMemoria) and location/contact info.

Ensure all components use modular React + Tailwind CSS structured for Vite with smooth transitions....attached on the prompt is the venus logo that you will use
